PharmInform
===========

Clinical pharmacogenomics platform: star allele calling, CPIC/DPWG dosing
guidance, and an experimental multi-gene composite risk score for drugs
affected by more than one pharmacogene.

See the project `README <https://github.com/YOUR_GITHUB_USERNAME/pharminform#readme>`_
for install instructions, usage examples, GeT-RM validation status, and
the composite risk scoring methodology. This Sphinx site currently covers
the API reference only.
